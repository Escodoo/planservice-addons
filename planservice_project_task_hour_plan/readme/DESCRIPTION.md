Split a task's allocated hours across the calendar months between its
planned start and end dates, or the other way around: fill the monthly
hour plan first and let it populate the planned dates and allocated time.

Each line is a calendar month: **From** and **To** are always the first
and last day. Pick the month directly when filling the plan by hand.

The first split from dates is equal (with the rounding remainder on the
last month). Each monthly line can then be edited so the effort can
follow a different curve, for example 10% / 50% / 20% / 20%.
**Capacity (%)** shows how much of one resource's configured monthly
hours (default 160) that month represents; editing it recomputes the
planned hours. Display follows the company's timesheet encoding method
(hours or days); values are stored in hours.
