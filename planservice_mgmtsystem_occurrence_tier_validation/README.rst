Add tier validation on occurrence records when they are waiting for
verification. Closing the record requires the configured reviewers. A
second definition covers concession requests.

.. contents::
   :local:

Configuration
=============

Go to **Settings > Technical > Tier Validations > Tier Definition**.

Two definitions are created on install:

- *Occurrence verification* — reviewer is the inspector on the record
- *Occurrence concession* — reviewer is any Management System Manager
  when *Concession required* is set

Adjust the domain, reviewers or sequence as needed.

Usage
=====

After the supplier submits a response, a validation review is created
for the inspector. Approving and closing the occurrence is blocked until
the review is accepted.

If a concession is required, the Management System Manager group must
also validate the record.

Rejecting a review returns the occurrence to the supplier.
