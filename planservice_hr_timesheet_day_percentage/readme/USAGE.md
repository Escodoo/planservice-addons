1. Open a timesheet list or the **Timesheets** tab on a task.
2. Set **Actual %** (for example 50). **Time Spent** is filled from the employee's average
   hours per day (50% of 8 h = 4 h).
3. Editing Time Spent updates Actual % the other way around.
4. Saving a line that would take the employee over 100% for that date is refused, even
   if the other lines are on different projects or tasks.

In Portuguese (pt_BR), "Planilha(s) de horas" is renamed to **Lançamentos** in menus,
actions, fields, access groups and views, since entries are a percentage of the day.
The renaming is applied again whenever translations are reloaded. Texts that live in
Python or JavaScript code (some buttons and breadcrumbs) keep the original wording.
