Apply the Planservice brand color to the Odoo backend.

The navbar and primary buttons use ``#D01000`` in the light color
scheme. Enterprise dark mode uses a slightly darker red so the bar stays
readable against the dark workspace. Link and focus colors keep the
standard Odoo action teal.

Usage
=====

Install **Planservice Web Theme** and reload the backend (or update the
module so web assets are rebuilt).

The change is global for every company in the database. Document layout
colors (PDF and email) and the Website theme palette are not affected;
configure those separately if they should match.
