- Na ficha de um projeto, o botão **Custo do projeto** (visível ao gerente de
  timesheet) abre o dashboard filtrado nessa obra, para todo o período.
- O dashboard também fica no menu Timesheets > **Custo de pessoal por obra**. O
  filtro da obra fica salvo no usuário; remova-o pelo × do botão de filtro.
- O filtro por obra usa o ID do projeto, então obras com nomes parecidos não se
  confundem. O Boardkit combina filtros com "E": use uma obra por vez.
- O filtro de período vale para todos os itens, inclusive o custo previsto, que é
  distribuído pelos meses das tarefas.
