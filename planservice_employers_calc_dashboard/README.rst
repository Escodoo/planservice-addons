Dashboard Boardkit **Custo de pessoal por obra** (custo previsto × real
× desvio, por obra, colaborador e mês) e um botão **Custo do projeto**
na ficha do projeto, que abre o dashboard já filtrado nessa obra.

Depende de ``planservice_employers_calc`` (que fornece a view de dados)
e de ``boardkit_dashboard``.

Usage
=====

- Na ficha de um projeto, o botão **Custo do projeto** (visível ao
  gerente de timesheet) abre o dashboard filtrado nessa obra, para todo
  o período.
- O dashboard também fica no menu Timesheets > **Custo de pessoal por
  obra**. O filtro da obra fica salvo no usuário; remova-o pelo × do
  botão de filtro.
- O filtro por obra usa o ID do projeto, então obras com nomes parecidos
  não se confundem. O Boardkit combina filtros com "E": use uma obra por
  vez.
- O filtro de período vale para todos os itens, inclusive o custo
  previsto, que é distribuído pelos meses das tarefas.

Known issues / Roadmap
======================

Módulo **temporário**, a ser removido junto com
``planservice_employers_calc`` quando o módulo financeiro for
implantado.

- Plano de saída: desinstalar este módulo antes do principal. O
  dashboard criado na instalação leva um xmlid do módulo e é apagado na
  desinstalação.
- O Boardkit não oferece um seletor de obra com busca nem filtro por
  URL; o botão do projeto contorna isso gravando o filtro do usuário. Se
  o Boardkit ganhar esses recursos, o botão pode ser simplificado.
- Os nomes do dashboard e dos itens ficam em português nos dados e não
  passam pelo ``pt_BR.po``. Se o dashboard virar multilíngue, traduzir
  pelos registros.
