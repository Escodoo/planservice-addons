Open in list view every window action that would open in kanban.

Odoo shows the first view of an action's view list when a menu is opened.
This module moves the list view to the first position of every action that
starts with kanban and has a list view, so apps open in list view instead of
kanban. The other views remain available in the view switcher.

Actions that start with another view, such as a form, a calendar or a report,
keep their order.
