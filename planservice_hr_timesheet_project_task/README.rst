Log timesheets by selecting a project only. The task is filled
automatically from the tasks assigned to the current user on that
project. The Time Spent field is hidden; the user only enters the day
percentage.

.. contents::
   :local:

Usage
=====

1. Open a timesheet list.
2. Select the **date** and the **project**. Only projects with tasks
   assigned to you are available.
3. The **task** is filled automatically from your assigned tasks on that
   project.
4. Enter a short **description** and the **Day %**.
5. Time Spent is computed from the day percentage and hidden from the
   view.
