Extend management-system nonconformities with a field occurrence
register (RO): classification, work division, technical reference,
evidence, supplier response, treatment plan and inspector verification.

The workflow is inspector → supplier → inspector, using dedicated stages
for release to the supplier and waiting verification.

Configuration
=============

No extra settings are required. Immediate action types and the Field
Occurrence origin are created on install.

Optional stages *Analysis* and *Action Plan* from the base module stay
available but are folded in the kanban. The occurrence flow uses
**Draft**, **Waiting Supplier**, **In Progress**, **Waiting
Verification** and **Closed**.

Usage
=====

Go to **Management System > Nonconformities** and create a record.

1. Fill the classification, project, supplier, description and evidence.
2. Click **Release to Supplier**. The partner is subscribed and can
   answer.
3. The supplier (backend or portal) fills containment, cause,
   disposition and the treatment plan, then clicks **Submit Response**.
4. The inspector reviews the record and chooses **Approve and Release**,
   **Approve with Comments**, **Reject**, **Keep Open** or
   **Reclassify**.

Closing still requires the inspector opinion. Treatment actions must be
done before the occurrence is closed, except when the disposition is
*Conclude without Intervention*.
