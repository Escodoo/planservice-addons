Go to **Management System > Nonconformities** and create a record.

1. Fill the classification, project, supplier, description and evidence.
2. Click **Release to Supplier**. The partner is subscribed and can answer.
3. The supplier (backend or portal) fills containment, cause, disposition
   and the treatment plan, then clicks **Submit Response**.
4. The inspector reviews the record and chooses **Approve and Release**,
   **Approve with Comments**, **Reject**, **Keep Open** or **Reclassify**.

Closing still requires the inspector opinion. Treatment actions must be
done before the occurrence is closed, except when the disposition is
*Conclude without Intervention*.
